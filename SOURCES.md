# SOURCES — historical facts shown on screen

This is stylized history, not alternate history. Every date, name, rank and outcome shown on screen appears in the table below. There are **no troop numbers or casualty figures** in the edit, because estimates vary widely between sources (for 1812 especially). There is **one quotation**, and it has been verified (see the bottom of this file).

## Verification method

- **Web-verified in this session** (marked ✅): checked against the pages linked below. These are Fondation Napoléon / napoleon.org, Britannica, Wikipedia (with its cited references), the napoleon-series.org treaty text, Berkeley Law and the Légifrance copy of the Constitution of Year VIII, and the 100days.org.uk archive.
- **Standard chronology** (marked ●): these match the standard reference chronologies listed below. They were not individually re-fetched in this session because the build container's network policy blocked most history sites. Spot-check before publication if you need a formal citation for every line.

### Reference works for the chronology
- David G. Chandler, *The Campaigns of Napoleon* (1966)
- Andrew Roberts, *Napoleon the Great* (2014)
- Philip Dwyer, *Napoleon: The Path to Power* (2007) and *Citizen Emperor* (2013)

## The one quotation ✅

> « L'aigle, avec les couleurs nationales, volera de clocher en clocher jusqu'aux tours de Notre-Dame. »

This is from Napoleon's proclamation to the army, dated **Golfe-Juan, 1 March 1815**. Sources:
- 100days.org.uk — [The Golfe-Juan proclamations](https://100days.org.uk/items/show/11)
- napoleon-monuments.eu — [1er mars 1815](https://napoleon-monuments.eu/Napoleon1er/18150301.htm)
- napoleon-histoire.com — [Correspondance de Napoléon, mars 1815](https://napoleon-histoire.com/correspondance-de-napoleon-mars-1815/)

The screen shows the French original with that attribution. To remove it, set `SHOW_EAGLE_QUOTE = false` in `src/scenes/HundredDays.tsx`.
